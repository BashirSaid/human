# لوحة مُركِّز الحوسبة — الأستاذ بشير سعيد

بوستر تعريفيّ بالرؤية التعليميّة والاجتماعيّة لمُركِّز الحوسبة والتعلُّم الرقميّ
في المدرسة الإعداديّة «فيّاض أسدي» — دير الأسد.

## الملفّات

| الملفّ | الوصف |
|---|---|
| `index.html` | اللوحة كاملةً (تصميم + نصّ). افتحها في المتصفّح. |
| `assets/seal.png` | شعار المدرسة، مقصوصٌ دائريًّا بخلفيّةٍ شفّافة. |
| `assets/portrait.jpg` | الصورة الشخصيّة، مُعالَجةٌ لونيًّا لتتناسب مع لوحة الألوان. |

## الطباعة

اضغط زرّ **«طباعة / حفظ PDF»** أسفل اللوحة، أو `Ctrl/Cmd + P`.
الصفحة مُعدّة مسبقًا لمقاس **A3 عموديّ** بلا هوامش.

## التعديل

نصّ الرؤية مكتوبٌ كمسوّدة قابلة للتبديل. كلّ بندٍ في `index.html` بهذا الشكل:

```html
<li>
  <div>
    <h3>عنوان البند</h3>
    <p>شرح البند.</p>
  </div>
</li>
```

المسافات العموديّة تتوزّع تلقائيًّا (`justify-content:space-between`)، فلا حاجة
لضبط الهوامش يدويًّا بعد تغيير النصّ. لتغيير الألوان، عدِّل متغيّرات `:root`
في أعلى ملفّ `index.html` — وهي مأخوذة أصلًا من ألوان شعار المدرسة.

## الخطوط

- **Reem Kufi** للعناوين — خطٌّ كوفيٌّ حديث، والكوفيّ المربّع مبنيٌّ على الشبكة
  تمامًا كشبكة البكسل.
- **IBM Plex Sans Arabic** للمتن.
- **Noto Sans Hebrew** للسطر العبريّ.

تُحمَّل من Google Fonts؛ وعند غياب الاتّصال يعود المتصفّح إلى خطوط النظام.
